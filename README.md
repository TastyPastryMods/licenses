# TastyPastry Licenses

This repository contains public license texts used by TastyPastry for Factorio mods and related projects.

## Available Licenses

### TP-SANR-1.0

**Full name:** TastyPastry Source-Available No-Redistribution License  
**Short identifier:** TP-SANR-1.0  
**License file:** [TP-SANR-1.0.md](./TP-SANR-1.0.md)

TP-SANR-1.0 is a source-available license intended to allow normal use, inspection, private local modification, dependency references, official Mod Portal links, videos, streams, screenshots, reviews, tutorials, and small bug-report excerpts while preventing unauthorized redistribution, reuploads, public forks, bundled copies, or modified public releases.

## Summary

Unless a specific project says otherwise, projects using TP-SANR-1.0 generally allow:

- Downloading and using the project from its official distribution source
- Inspecting and studying the files
- Making private local modifications for personal use
- Linking to the official distribution page
- Listing the project as a dependency
- Creating videos, streams, screenshots, reviews, tutorials, and similar media
- Sharing small excerpts for bug reports or compatibility discussions

TP-SANR-1.0 generally does not allow:

- Redistributing the project files
- Reuploading the project
- Mirroring the project files
- Bundling the project files in another download
- Publishing modified versions
- Publishing continuation forks without permission
- Reusing substantial portions of the code or assets without permission

See the full license text for the actual terms.
